## Understand it first (before you do anything)
**What is it?** A knowledge graph stores things (nodes) and relationships (edges). Cypher is its query language.

**How does it work?** MATCH a pattern of nodes and edges > WHERE filter > RETURN

**Answer these in your `ACTIVITY_LOG.md` before you start the steps:**
- What is a node, a label, a relationship, a property?
- How is a graph different from joining tables?
