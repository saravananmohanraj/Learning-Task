## Understand it first (before you do anything)
**What is it?** Business definitions (what 'open', 'won' and 'deal value' mean) are knowledge: stable facts the agent should look up rather than guess.

**How does it work?** glossary.md > chunk/embed > knowledge base > agent searches it when a term appears > answer uses the definition

**Answer these in your `ACTIVITY_LOG.md` before you start the steps:**
- Why not put the glossary in the instructions?
- How do you verify the agent used the definition and not its own guess?

## What to do
1. Write 8-10 definitions in markdown (open, won, deal value, latest version...)
2. Load as knowledge for your day-8 agent
3. Ask questions needing both definition and data; confirm the definition was used

Work through these in order. After each step, write down what you expected, what really happened, and why.
