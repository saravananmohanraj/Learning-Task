## Understand it first (before you do anything)
**What is it?** The evaluation scores the agent against expected answers from your own SQL and explains each failure.

**How does it work?** questions > run agent > compare with expected > score > analyse > improve > re-run

**Answer these in your `ACTIVITY_LOG.md` before you start the steps:**
- What do you look at first when the score is low?
- Is full marks proof the agent is good?

## What to do
1. 10 questions with expected answers from your own SQL
2. Run, record score, analyse failures, improve once, re-run

Work through these in order. After each step, write down what you expected, what really happened, and why.
